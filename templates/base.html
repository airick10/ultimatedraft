HOW TEMPLATE INHERITANCE WORKS (the idea behind all the pages) A page like baseball.html starts with {% extends "base.html" %} which means "use base.html as my outer frame and fill in its blanks". The blanks are the {% block name %} ... {% endblock %} pairs below. Each child page supplies content for the blocks it cares about; anything it leaves out keeps base.html's own content. Inside a child's block, {{ super() }} means "also include what the parent put in this block". THE BLOCKS DEFINED HERE css in , BEFORE Bootstrap. Holds styles.css by default; children add their own stylesheets. title the browser tab's title. body the page content. scripts at the very end of , AFTER Bootstrap's script. Children add their own scripts.
